### 口径（重要）
1. **钓点鱼池由「水域表」决定，非一一对应**：
   | 钓点 | 可刷 AppearType |
   |---|---|
   | 河流 | 河流 / 所有河 |
   | 池塘 | 池塘 / 所有河 |
   | 悬崖上 | 悬崖上 / **河流** / 所有河 |
   | 出海口 | 出海口 / **河流** / 所有河 |
   | 大海 | 大海 / 所有海 |
   | 栈桥 | 栈桥 / **大海** / 所有海 |
   → "河流"型鱼同时出现在 河流/悬崖上/出海口 三个钓点；"大海"型鱼同时出现在 大海/栈桥。
2. 咬钩概率 P = Weight / 该池 ΣWeight（引擎加权轮盘）。
3. 组合期望售价 **E = Σ(Weight×Price) / ΣWeight**（加权平均价格，无需先算逐鱼概率）。
4. 三时段档等长（各约 8h）→ **每月每钓点期望收益 = 三档 E 的算术平均**（空池档跳过）。
5. **验证**：自算概率与「鱼分析表」P~U 列缓存值抽样 1962 点全部一致（maxdiff 1e-16）。

### 读出的结论
- **夏季 6–9 月是收益旺季**，9 月峰值（均值 1457，悬崖上 1806 为全局最高）；1–2 月与 4 月最低（均值 443–594）。
- **池塘是"逆周期保底"钓点**：4–9 月旺季时它反而垫底（400–820），但 12 月冲到 1075（当月第一），季节性最平缓（CV 最低）。
- **河流/悬崖上/出海口三者在 6–9 月高度同步**——因为"河流"型鱼同时属于这三个钓点，夏季高价鱼（骨舌鱼/巨骨舌鱼 10000 等）一上市，三点同时被拉高。
- 悬崖上 9 月 1806 是全表最大值；出海口 11 月 995 是它的局部高点。

### 图型选择理由
- **分组柱状图**：数据是"月 × 钓点"的离散绝对量，柱状对绝对值感知最准；叠加河系均值折线补趋势。
- **热力图**：12×4 矩阵全景，一眼定位最优 (月,钓点)，黑框标每月最优。
- 未选折线图作为主图：河流/悬崖上/出海口在 6–8 月数值完全重合，折线会互相覆盖。

### 河海对比（重要结论）
| 指标 | 河鱼（4 钓点均值） | 海鱼（2 钓点均值） |
|---|---|---|
| 区间 | 443 ~ 1457 | 1199 ~ 1694 |
| 极差 | 1014 | 495 |
| 相对波动(CV) | ≈ 38% | ≈ 13% |
| 最低月 | 4月 443 | 4月 1199 |
| 最高月 | 9月 1457 | 9月 1694 |

- **海鱼期望收益全面高于河鱼，且波动只有河鱼的三分之一**：海钓 = 稳定高收益；河钓 = 季节性爆发（6–9 月才追上）。
- 栈桥与大河钓点的差异：栈桥比大海高 80~250 铃钱/次（3月差 288 最大），因栈桥专属高价鱼（旗鱼 10000 / 鲔鱼 7000 / 鬼头刀 6000 / 白面弄鱼 4000）。
- 两者旺季均在 7–9 月（9 月峰），谷底均在 4 月，季节性节奏一致。
