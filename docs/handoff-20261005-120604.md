### 关键认知修正（务必以此为准，早期理解有误）

1. **Area 0 / Area 1 = 南北半球**，不是河流/池塘。已验证：Area1 权重 = Area0 平移 +6 个月（50/50 条鱼吻合）。
2. **总表结构** = 每条鱼 × 12月 × 3时段 **全展开（36 行）**，非活跃月 `Weight=0`。判定"活跃"必须用 `Weight>0`。
3. **列序**：`2 Size` 才是影子档（SS/S/M/L/LL/LLL/J/K/U）；`4 BuoyLv` 是 `('0','1')` 形式的难度区间。早期把两者混淆。
4. **Σw=100 的真实含义**：只是"单张表内所有候选鱼的归一化总和"，是引擎读取约定，不是概率接口。
   - 精确口径（第5轮修正）：**Σw=100 只在单个（月×时段×单一钓点列）严格成立**；跨 4 个河系钓点加总为 117–136，跨 2 个海系钓点为 97–107。
5. **空罐 3466 权重**：River 表=2、Sea 表=1，两表本就不同，用户区分正确，非错误。
6. **用户总表 = 一张"可视化概率表"**（列内 prob 和=1），比原表更接近玩家真实体验。
