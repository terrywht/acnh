### 第 10 轮：每月每钓点期望收益

**关键前提**：「水域表」定义**钓点 → AppearType 从属关系，非一一对应**：

| 钓点 | 可刷 AppearType |
|---|---|
| 河流 | 河流 / 所有河 |
| 池塘 | 池塘 / 所有河 |
| 悬崖上 | 悬崖上 / **河流** / 所有河 |
| 出海口 | 出海口 / **河流** / 所有河 |
| 大海 | 大海 / 所有海 |
| 栈桥 | 栈桥 / **大海** / 所有海 |

**口径**：`P = Weight / 该池 ΣWeight`；组合期望售价 `E = Σ(Weight×Price) / ΣWeight`；三时段档等长 → 月值 = 三档 E 算术平均（空池档跳过）。
**验证**：自算概率与「鱼分析表」P～U 列缓存值抽样 **1962 点全一致**（maxdiff 1e-16）。

**产出**：`analysis/河鱼期望收益.csv` / `海鱼期望收益.csv`（12 月 × 钓点 + 均值）、`*_分组柱状.png`（主图）、`*_热力图.png`（辅助，黑框标每月最优）。

### 本轮硬结论（可直接引用）

- **海鱼期望收益全面高于河鱼，且波动只有河鱼的三分之一**：海 1199–1694（CV ≈ 13%）vs 河 443–1457（CV ≈ 38%）。海鱼**最低月（4 月 1199）已超河鱼全年均值**。
- **设计取舍**：海钓 = 稳定高收益（低方差）；河钓 = 季节性爆发（高方差）。叠加"池塘"逆周期钓点（旺季垫底 400–820、12 月冲到 1075），玩法即 **"想稳就出海，想赌夏季大鱼就蹲河里"**。
- **河流 / 悬崖上 / 出海口高度同步**（6–8 月数值完全重合）——因"河流"型鱼同属这三个钓点。
- **栈桥恒高于大海**（栈桥 ⊇ 大海），差额来自旗鱼 10000 / 鲔鱼 7000 / 鬼头刀 6000 / 白面弄鱼 4000 等栈桥专属高价鱼（3 月差额最大 +288）。
- **排期层与经济层曲线同构**：出没鱼种数（第 9 轮）与期望收益（第 10 轮）都是**夏峰冬谷**。
