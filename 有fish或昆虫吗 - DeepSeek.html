1. 核心主表：FishStatusParam.csv（物种百科全书）

这是鱼的“基因库”，定义了每种鱼在游戏引擎中的基础物理和行为参数。它通过 ItemID 与出现表关联，通过 UniqueID 与任务表关联。

关键字段解析：

  • AppearArea / AppearType：声明这条鱼属于“川”、“池”、“海”、“汽水池”、“崖上”还是“码头”。（注意：出现表里的 AppearArea 0/1 是具体点位细分，这里是大类匹配）。

  • ShadowType：鱼影大小（SS/S/M/L/LL/LLL/U/J/K 等），决定了玩家在水面看到的影子尺寸。

  • BuoyLv：浮标交互模式（咬钩的节奏和动作类型）。

  • EscapeScale：脱钩倍率（数值越高，按 A 键的判定帧越严格，鱼越难拉上来）。

  • SearchRadius：鱼发现鱼饵的索敌半径。

  • ResName：调用对应的 3D 模型和博物馆模型。

2. 时空规则表：FishAppearRiverParam.csv 与 FishAppearSeaParam.csv

这两张表是“排班表”。游戏根据玩家当前所在的地理位置（河流或大海/码头）来决定读取哪张表。

逻辑解析：

  • 列名结构：Prob[月份][时间段]。例如 ProbAprDaytime 代表“4月白天”的出现概率权重。

  • 时间段：Daytime（白天）、MorningAndEvening（早晚）、Night（夜晚）。

  • AppearArea（0 或 1）：这是同一条河流/海域内的细分区域（比如 0 代表“上游/普通海域”，1 代表“下游出海口/远海”）。当你在河口或码头钓鱼时，系统会优先看 AppearArea=1 的数据。

  • 概率权重：数字（如 20、10、0）代表相对权重，而非百分比。游戏会计算当前月份+时段下所有鱼的权重总和，然后进行加权随机抽选，抽中的 ItemID 即为将要生成的鱼种。

3. 活动任务联动表：FishBeyQuestParam.csv

这张表是“任务过滤器”，主要用于钓鱼大会（Fishery Tourney）或里程挑战。

  • UniqueID：对应 FishStatusParam 里的鱼种 ID。

  • IsSelectQuestM / S / SS：这里的 M、S、SS 指的是任务难度或尺寸等级（并非鱼影大小，而是活动要求的特定尺寸区间，例如钓起“XX cm 以上的鱼”）。如果为 1，则表示这条鱼会被纳入对应等级的任务抽选池中，为 0 则不计入。

  1. 定位与环境判定：检测玩家所在位置 → 确定读取 River 表还是 Sea 表；检测当前月份、当前时间段（白天/早晚/夜晚）；检测具体点位（AppearArea 为 0 还是 1）。

  3. 随机抽选物种：根据权重随机抽取一个 ItemID。如果抽到的权重是 0，则该鱼在此条件下不可能出现（比如冬季的鲨鱼）。

  4. 调用实体参数（生成鱼影）：拿着选中的 ItemID 去 FishStatusParam.csv 中查找：

    • 根据 ShadowType 决定在水面上显示多大的鱼影。

    • 根据 SearchRadius 决定鱼影感知玩家的距离（是否会警觉逃走）。

    • 根据 ResName 加载鱼的模型。

  5. 玩家抛竿后的交互（BuoyLv 登场）：当鱼影咬住浮标时：

    • 玩家在正确的时机按 A 键“提竿”后，系统立刻计算 EscapeScale（脱钩率），结合玩家按键时机，判定本次是成功钓起还是鱼逃脱。

  6. 收线后的判定（特殊任务）：当鱼成功入袋后，系统测量该鱼的实际尺寸（长度/重量）。如果当前有钓鱼大会活动，系统会检索 FishBeyQuestParam.csv，根据该鱼的 UniqueID 和测得的身长，判断是否满足 IsSelectQuestM/S/SS 的条件，从而给予对应的积分或奖杯。

二、高级鱼 vs 低级鱼：如何界定与分配？

在动森中，“高级”并非由官方标签定义，而是由“生态位 + 参数枷锁”决定的。设计师通过三个硬性指标来区分：

  1. ShadowType（鱼影大小）：这是玩家第一感知。S/M 大概率是低价杂鱼，LL/LLL/J/U/K 对应高价鱼（如金鱼、鲨鱼）。

  2. 出现水域限制（AppearArea / AppearType）：低级鱼遍布全河（Area 0+1），高级鱼往往被绑定在特定高危区域（如 RiverCliffTop 悬崖上、SeaBeachBridge 码头尽头）。迫使玩家承担“往返跑路”的时间成本。

  3. 概率权重的绝对压制（Prob 数值）：

设计师保证高级鱼低概率的数学公式是：“绝对低基数（1~2）” + “高分母池（总和 100~200）”。
